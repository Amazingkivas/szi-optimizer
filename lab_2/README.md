# Lab 2 — Задача о назначениях с ограничениями

Этот проект является копией базового шаблона и реализует постановку из `lab_2.pdf`:
приближенное решение задачи о назначениях с дополнительными ограничениями методом Узавы.

## Формат входных данных API `/api/solve`

```json
{
  "cost_matrix": [[...], [...]],
  "constraints": [ [[...]], [[...]] ],
  "bounds": [b1, b2],
  "lambda0": [1, 1],
  "step_size": 0.1,
  "max_iter": 200,
  "tolerance": 1e-6
}
```

- `cost_matrix` — квадратная матрица C.
- `constraints` — список матриц D^k того же размера.
- `bounds` — правая часть ограничений b_k.
- `lambda0`, `step_size`, `max_iter`, `tolerance` — параметры субградиентных итераций.
