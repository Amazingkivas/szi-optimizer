# Lab 3 — Задачи об огневой мощи противника

Этот проект является копией базового шаблона и реализует задачу из `lab_3.pdf`.
Поддержаны варианты:

- `task1`: ослабление выбранного подразделения в `k` раз на один период;
- `task2`: ослабление на два периода (модифицированная матрица `\tilde{C}`).

## Формат входных данных API `/api/solve`

```json
{
  "c_matrix": [[...], [...]],
  "k": 2.0,
  "variant": "task1"
}
```

Где `variant` может быть `task1` или `task2`.
